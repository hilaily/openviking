    📦 核心模块详解¶

    Client 层¶

    用户直接交互的入口。

    客户端 说明 适用场景
    SyncOpenViking 同步客户端 简单脚本、单进程应用
    AsyncOpenViking 异步客户端 高并发、Web 服务
    HTTPClient HTTP 客户端 跨语言、分布式部署

    Service 层¶

    业务逻辑处理，将业务与传输解耦。

    服务 职责 关键方法
    FSService 文件系统操作 ls, mkdir, rm, mv, read, glob
    SearchService 语义搜索 search, find
    SessionService 会话管理 session, commit, delete
    ResourceService 资源导入 add_resource, wait_processed
    RelationService 关联管理 relations, link, unlink
    PackService 导入导出 export_ovpack, import_ovpack
    DebugService 调试 observer

    Retrieve（检索模块）¶

    负责从存储中检索相关上下文。

    组件 职责
    IntentAnalyzer 意图分析，将用户查询转换为结构化查询
    HierarchicalRetriever 目录递归检索
    Reranker 重排序，提高准确性

    Session（会话模块）¶

    管理对话和提取记忆。

    组件 职责
    SessionCompressor 压缩归档历史消息
    MemoryExtractor 从消息中提取 6 种分类记忆
    Compressor 记忆去重决策

    Parse（解析模块）¶

    处理外部资源导入。

    组件 职责
    DocumentParser 解析各种文档格式
    TreeBuilder 构建目录树结构
    SemanticQueue 异步生成 L0/L1 语义信息

    Storage Layer¶

    双层存储架构。

    存储层 职责 内容
    VikingFS URI 抽象层 统一操作接口
    AGFS 内容存储 L0/L1/L2 完整内容
    向量数据库 索引存储 URI、向量、元数据
    Observer 事件监听 状态变化通知

    🎯 设计原则¶

    原则 说明 实践
    存储层纯粹 存储层只做存储和基础搜索 Rerank 在检索层完成
    三层信息 L0/L1/L2 按需加载 节省 Token
    两阶段检索 向量召回 + Rerank 精排 提高准确性
    单一数据源 所有内容从 AGFS 读取 向量库只存引用
