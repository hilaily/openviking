## 🚀 编写第一个示例

创建 `example.py`：

```python
import openviking as ov

# 初始化客户端（指定数据目录）
client = ov.SyncOpenViking(path="./data")

try:
    # 1. 初始化
    client.initialize()

    # 2. 添加资源（支持 URL、文件、目录）
    add_result = client.add_resource(
        path="https://raw.githubusercontent.com/volcengine/OpenViking/refs/heads/main/README.md"
    )
    root_uri = add_result['root_uri']
    print(f"资源已添加: {root_uri}")

    # 3. 查看目录结构
    ls_result = client.ls(root_uri)
    print(f"\n目录结构:\n{ls_result}")

    # 4. 查找 Markdown 文件
    glob_result = client.glob(pattern="**/*.md", uri=root_uri)
    if glob_result['matches']:
        content = client.read(glob_result['matches'][0])
        print(f"\n文件内容预览:\n{content[:200]}...")

    # 5. 等待语义处理完成
    print("\n等待语义处理...")
    client.wait_processed()

    # 6. 获取摘要和概览
    abstract = client.abstract(root_uri)
    overview = client.overview(root_uri)
    print(f"\nL0 摘要:\n{abstract}")
    print(f"\nL1 概览:\n{overview}")

    # 7. 语义搜索
    results = client.find("what is openviking", target_uri=root_uri)
    print("\n搜索结果:")
    for r in results.resources:
        print(f"  {r.uri} (score: {r.score:.4f})")

    # 8. 关闭客户端
    client.close()

except Exception as e:
    print(f"错误: {e}")
```

## 🔍 代码解析

### 1. 初始化

```python
client = ov.SyncOpenViking(path="./data")
client.initialize()
```

- 创建客户端实例，指定数据存储目录
- 初始化本地存储和向量索引

### 2. 添加资源

```python
client.add_resource(path="...")
```

- 支持 URL、文件路径、目录
- 自动解析文档结构
- 异步生成 L0/L1 语义信息

### 3. 文件系统操作

```python
client.ls(uri)      # 列出目录
client.read(uri)     # 读取文件
client.glob(...)     # 模式匹配
client.abstract(uri) # 获取 L0
client.overview(uri) # 获取 L1
```

- 类似本地文件系统的操作方式
- 但操作的是虚拟文件系统

### 4. 语义搜索

```python
client.find(query, target_uri=...)
```

- 在指定范围内搜索
- 使用向量相似度 + 目录递归检索

## 🐛 常见问题

### Q: 报错 "api_key missing"

A: 检查配置文件路径和环境变量是否正确设置

### Q: 向量搜索没结果

A: 确保调用了 `wait_processed()` 等待语义处理完成

### Q: 内存占用太高

A: 可以使用本地 vLLM 模型，减少 API 调用
