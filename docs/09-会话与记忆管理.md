# 09 - 会话与记忆管理

> Session 模块负责管理对话历史，并从中提取长期记忆，让 Agent 越用越聪明。

---

## 🎯 会话生命周期

```
┌─────────────────────────────────────────────────────────────────┐
│                      会话生命周期                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   创建会话                                                       │
│       │                                                         │
│       ▼                                                         │
│  ┌──────────────────┐                                           │
│  │   添加消息        │  ←  持续添加用户/助手消息                   │
│  │  add_message()   │                                           │
│  └────────┬─────────┘                                            │
│           │                                                      │
│           ▼                                                      │
│  ┌──────────────────┐                                           │
│  │   记录使用        │  ←  记录使用了哪些上下文                   │
│  │     used()       │                                           │
│  └────────┬─────────┘                                            │
│           │                                                      │
│           ▼                                                      │
│  ┌──────────────────┐                                           │
│  │   提交会话        │  ←  归档 + 提取记忆                        │
│  │   commit()      │                                           │
│  └──────────────────┘                                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 📝 核心 API

### 创建/获取会话

```python
# 创建新会话
session = client.session(session_id="chat_001")

# 或获取现有会话
session = client.session(session_id="existing_session")
```

### 添加消息

```python
# 添加用户消息
session.add_message(
    "user",
    [{"type": "text", "text": "我喜欢深色模式"}]
)

# 添加助手消息（可包含上下文引用）
session.add_message(
    "assistant",
    [
        {"type": "text", "text": "好的，已记住。"},
        {"type": "context", "uri": "viking://user/memories/profile.md"}
    ]
)
```

### 记录上下文使用

```python
# 记录使用的上下文
session.used(contexts=[
    "viking://user/memories/preferences/coding.md"
])

# 记录使用的技能
session.used(skill={
    "uri": "viking://agent/skills/code-search",
    "input": "search config",
    "output": "found 3 files",
    "success": True
})
```

### 提交会话（核心操作）

```python
result = session.commit()
# {
#   "status": "committed",
#   "memories_extracted": 5,
#   "active_count_updated": 2,
#   "archived": True
# }
```

## 💬 消息结构

### Message

```python
@dataclass
class Message:
    id: str              # 消息 ID (msg_{UUID})
    role: str            # "user" | "assistant"
    parts: List[Part]    # 消息部分
    created_at: datetime # 创建时间
```

### Part 类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **TextPart** | 文本内容 | `{"type": "text", "text": "Hello"}` |
| **ContextPart** | 上下文引用 | `{"type": "context", "uri": "..."}` |
| **ToolPart** | 工具调用 | `{"type": "tool", "name": "search", ...}` |

### 存储格式

消息以 JSONL 格式存储在会话目录：

```
viking://session/{session_id}/
├── messages.jsonl           # 当前消息（逐行 JSON）
├── .abstract.md             # 当前会话摘要
├── .overview.md             # 当前会话概览
├── history/
│   ├── archive_001/         # 历史归档
│   │   ├── messages.jsonl
│   │   ├── .abstract.md
│   │   └── .overview.md
│   └── archive_002/
└── tools/
    └── {tool_id}/
        └── tool.json       # 工具调用记录
```

## 📦 消息压缩（归档）

当会话消息过多时，commit() 会自动压缩。

### 归档流程

```
1. 递增 compression_index
2. 复制当前消息到 history/ 目录
3. LLM 生成结构化摘要
4. 清空当前消息列表
```

### 摘要格式

```markdown
# 会话摘要

**一句话概述**: Python环境配置: 用户询问环境配置方法 | 已解决 | 成功

## Analysis
- 用户询问 Python 环境配置
- 提供了 virtualenv 配置步骤
- 用户确认理解

## Primary Request and Intent
了解如何配置 Python 开发环境

## Key Concepts
- virtualenv
- pip 包管理
- requirements.txt

## Pending Tasks
无
```

## 🧠 记忆提取（核心）

commit() 时会自动从消息中提取 6 种分类记忆。

### 6 种记忆分类

| 分类 | 归属 | 位置 | 说明 | 可合并 |
|------|------|------|------|--------|
| **profile** | user | `user/memories/` | 用户基本信息 | ✅ |
| **preferences** | user | `user/memories/preferences/` | 按主题偏好 | ✅ |
| **entities** | user | `user/memories/entities/` | 实体（人/项目） | ✅ |
| **events** | user | `user/memories/events/` | 事件/决策 | ❌ |
| **cases** | agent | `agent/memories/cases/` | 问题+解决方案 | ❌ |
| **patterns** | agent | `agent/memories/patterns/` | 可复用流程 | ✅ |

### 提取流程

```
消息 → LLM 提取 → 候选记忆
         │
         ▼
   向量预过滤 → 找相似记忆
         │
         ▼
   LLM 去重决策 → CREATE/UPDATE/MERGE/SKIP
         │
         ▼
     写入存储 → AGFS + 向量化
```

### 去重决策

| 决策 | 说明 | 场景 |
|------|------|------|
| **CREATE** | 新记忆，直接创建 | 没有相似的现有记忆 |
| **UPDATE** | 更新现有记忆 | 细节补充 |
| **MERGE** | 合并多条记忆 | 多条相关记忆合并 |
| **SKIP** | 完全重复 | 与现有记忆高度相似 |

### 去重示例

```
新提取的记忆: "用户喜欢简洁的回答风格"

现有记忆库:
[
    { "uri": "...", "content": "用户回答偏好简洁" },
    { "uri": "...", "content": "用户说不要太多废话" }
]

去重决策: MERGE (合并为一条更完整的记忆)
```

## 💻 代码示例

### 完整会话流程

```python
client = ov.SyncOpenViking(path="./data")
client.initialize()

# 1. 创建会话
session = client.session(session_id="project_kickoff")

# 2. 添加多轮消息
session.add_message("user", [
    {"type": "text", "text": "我们开始一个新项目，名字叫 Alpha"}
])

session.add_message("assistant", [
    {"type": "text", "text": "好的，我来创建项目记录"}
])

# 记录使用的上下文
session.used(contexts=[
    "viking://user/memories/entities/project_alpha"
])

# 3. 更多交互...
session.add_message("user", [{"type": "text", "text": "技术栈用 Python + FastAPI"}])
session.add_message("assistant", [{"type": "text", "text": "已记录"}])

# 4. 提交会话（自动提取记忆）
result = session.commit()
print(f"提取了 {result['memories_extracted']} 条记忆")

# 5. 检查提取的记忆
session2 = client.session(session_id="project_kickoff")
memories = client.find("项目 Alpha", target_uri="viking://user/memories/")
for m in memories.memories:
    print(f"{m.uri}: {m.abstract}")

client.close()
```
