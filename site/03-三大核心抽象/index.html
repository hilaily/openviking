    03 - 三大核心抽象¶

    OpenViking 将 Agent 需要的所有信息抽象为三种基本类型：资源、记忆、能力。

    🎯 概览¶

    类型 英文 用途 生命周期 主动性
    资源 Resource 外部知识 长期、静态 用户添加
    记忆 Memory 学习到的知识 长期、动态 Agent 记录
    能力 Skill 可调用的工具 长期、静态 Agent 调用

    📦 Resource（资源）¶

    资源是 Agent 可以引用的外部知识。

    核心特点¶

    特点 说明
    用户主动 由用户主动添加，补充大模型的知识
    静态内容 添加后很少变化，用户主动修改
    结构化存储 按项目/主题以目录层级组织

    示例场景¶

    用户向 Agent 添加产品文档：
"这是我们的 API 文档，请基于它回答用户问题"

Agent 现在可以回答：
- API 端点地址
- 认证方式
- 请求参数格式
- 错误码含义

    存储结构¶

    viking://resources/
├── api-docs/                    # 用户项目
│   ├── .abstract.md            # L0: 一句话概述
│   ├── .overview.md           # L1: 目录导航
│   ├── authentication.md       # L2: 详细内容
│   ├── endpoints.md
│   └── models.md
│
├── user-manual/                # 另一个项目
└── faq-database/

    API 使用¶

    # 添加资源
client.add_resource(
    "https://docs.example.com/api.pdf",
    reason="API 文档"
)

# 搜索资源
results = client.find(
    "认证方法",
    target_uri="viking://resources/"
)

    🧠 Memory（记忆）¶

    记忆是 Agent 从交互中学习到的知识，分为用户记忆和 Agent 记忆。

    核心特点¶

    特点 说明
    Agent 主动 由 Agent 自动提取和记录
    动态更新 从交互中持续学习
    个性化 针对特定用户或 Agent

    6 种记忆分类¶

    分类 归属 位置 说明 可合并
    profile 用户 user/memories/ 用户基本信息 ✅
    preferences 用户 user/memories/preferences/ 按主题的偏好 ✅
    entities 用户 user/memories/entities/ 实体（人物、项目） ✅
    events 用户 user/memories/events/ 事件/决策 ❌
    cases Agent agent/memories/cases/ 问题+解决方案 ❌
    patterns Agent agent/memories/patterns/ 可复用流程 ✅

    每种记忆详解¶

    1️⃣ Profile（用户画像）¶

    位置: viking://user/memories/profile.md

内容: 用户的基本信息
示例:
- 用户名: 张三
- 职位: 高级工程师
- 专长: Python、后端架构
- 工作节奏: 习惯异步沟通

    2️⃣ Preferences（偏好）¶

    位置: viking://user/memories/preferences/

结构:
├── writing_style/      # 写作风格偏好
│   └── brief/          # 喜欢简洁的回答
├── code_style/         # 代码风格偏好
│   └── type_hint/      # 使用类型提示
└── communication/      # 沟通偏好
    └── direct/         # 直接给出结论

    3️⃣ Entities（实体）¶

    位置: viking://user/memories/entities/

结构:
├── john_doe/           # 认识的一个人
│   └── profile.md      # 个人信息
├── project_alpha/      # 参与的项目
│   └── profile.md      # 项目信息
└── team_lead/          # 团队负责人

    4️⃣ Events（事件）¶

    位置: viking://user/memories/events/

示例:
├── 2024-01-15-decision-meeting/
│   └── summary.md      # 会议决策记录
├── 2024-02-20-project-kickoff/
└── 2024-03-10-tech-stack-chosen/

    5️⃣ Cases（案例）¶

    位置: viking://agent/memories/cases/

示例:
├── python-fastapi-auth/
│   ├── problem.md       # 问题描述
│   └── solution.md      # 解决方案
└── react-state-management/

    6️⃣ Patterns（模式）¶

    位置: viking://agent/memories/patterns/

示例:
├── error-handling-pattern/
│   └── log_retry_notify/
└── api-design-pattern/
    └── rest_crud_with_version/

    API 使用¶

    # 记忆从会话中自动提取
session = client.session()
session.add_message("user", [{"type": "text", "text": "我喜欢深色模式"}])
session.add_message("assistant", [{"type": "text", "text": "好的，已记住"}])
session.commit()  # 自动提取偏好记忆

# 搜索记忆
results = client.find(
    "用户界面偏好",
    target_uri="viking://user/memories/"
)

    ⚡ Skill（能力）¶

    技能是 Agent 可以调用的能力定义，如工具、Skills、MCP 等。

    核心特点¶

    特点 说明
    定义式 定义完成某工作的工具
    相对静态 定义不变，但使用经验会记录在记忆中
    可调用 Agent 决定何时使用哪种技能

    存储结构¶

    viking://agent/skills/{skill-name}/
├── .abstract.md          # L0: 一句话描述（用于检索）
├── SKILL.md              # L1: 详细说明（何时使用、如何使用）
└── scripts/              # L2: 完整定义（代码、配置）

    示例¶

    viking://agent/skills/search-web/
├── .abstract.md          # "网络搜索，获取实时信息"
├── SKILL.md              # 
│   # Search Web Skill
│   用于搜索网络获取最新信息。
│   ## 何时使用
│   - 用户询问实时新闻
│   - 需要获取最新数据
│   ## 如何使用
│   输入: 搜索关键词
│   输出: 搜索结果列表
└── scripts/
    └── definition.json   # 技能完整定义

    API 使用¶

    # 添加技能
await client.add_skill({
    "name": "search-web",
    "description": "搜索网络获取信息",
    "content": "# search-web\n..."
})

# 搜索技能
results = client.find(
    "网络搜索",
    target_uri="viking://agent/skills/"
)

    🔄 三者如何协同？¶

    ┌─────────────────────────────────────────────────┐
│                   用户提问                        │
│   "帮我查一下 OAuth 认证流程，然后写个示例代码"     │
└─────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────┐
│  1️⃣ 意图分析                                   │
│  - 需要技能: search-web（查文档）               │
│  - 需要资源: OAuth 指南文档                      │
│  - 需要记忆: 用户的代码风格偏好                  │
└─────────────────────────────────────────────────┘
                        │
        ┌───────────────┼───────────────┐
        ▼               ▼               ▼
┌───────────┐   ┌───────────┐   ┌───────────┐
│  Skills   │   │Resources  │   │  Memory   │
│ 查找搜索  │   │ OAuth 文档│   │ 代码偏好  │
│ 技能定义  │   │           │   │           │
└───────────┘   └───────────┘   └───────────┘
        │               │               │
        └───────────────┼───────────────┘
                        ▼
┌─────────────────────────────────────────────────┐
│  Agent 综合所有信息，生成回答                    │
│  使用用户偏好的风格，调用合适的技能              │
└─────────────────────────────────────────────────┘

    📊 总结对比¶

    维度 Resource Memory Skill
    内容来源 用户添加 Agent 提取 开发者定义
    变化频率 低 高 很低
    主要作用 补充知识 学习成长 执行任务
    检索优先级 中 中 高
    示例 API 文档、FAQ 用户偏好、对话历史 搜索、代码执行
