# 10 - 自动记忆迭代

> OpenViking 的终极目标：让 Agent 通过与用户的交互不断进化，越用越聪明。

---

## 🎯 什么是"记忆迭代"？

传统系统的记忆是**静态的**：
- 只记录对话历史
- 无法提炼经验
- 不会自我改进

OpenViking 的记忆是**动态的**：
- 自动提炼长期记忆
- 积累使用经验
- 持续优化行为

## 🧠 两类记忆进化

### 1. 用户记忆进化

随着交互，Agent 对用户的理解越来越深。

#### 例子：用户偏好学习

```
第 1 次交互:
用户: "我喜欢深色模式"
→ 提取: preference/ui_theme = "dark"

第 5 次交互:
用户: "回答尽量简洁，不要太多废话"
→ 提取: preference/communication = "brief"

第 10 次交互:
Agent 看到历史记忆:
- ui_theme: dark
- communication: brief
→ 自动组合: "用户偏好简洁直接的深色模式界面"
```

### 2. Agent 经验积累

从任务执行中学习最佳实践。

#### 例子：案例学习

```
任务: "帮我调试 Python 内存泄漏"

执行过程:
- 使用了 memory_profiler 工具
- 发现是字典持续增长
- 解决方案: 定期清理缓存

提取为案例:
{
  "problem": "Python 内存持续增长",
  "solution": "使用 memory_profiler 分析，发现字典未清理",
  "pattern": "遇到内存问题先用 memory_profiler 定位"
}

下次遇到类似问题:
- 自动检索这个案例
- 复用解决方案
```

## 📊 6 种记忆的更新策略

| 分类 | 更新策略 | 说明 |
|------|----------|------|
| **profile** | ✅ 追加 | 用户基本信息逐步积累 |
| **preferences** | ✅ 追加 | 偏好可以有多条，按主题组织 |
| **entities** | ✅ 追加 | 认识的人、项目越来越多 |
| **events** | ❌ 不更新 | 事件记录一次写入，不修改历史 |
| **cases** | ❌ 不更新 | 案例一旦形成，保持原样 |
| **patterns** | ✅ 可合并 | 模式可以提炼升华 |

### 为什么有的不更新？

- **events**: 历史决策需要保持原貌，供追溯
- **cases**: 解决方案一旦验证，不再改变
- **patterns**: 模式从案例中提炼，但案例保持原样

## 🔧 去重决策详解

当提取出新记忆时，系统会判断如何处理：

### 决策流程

```
新记忆
   │
   ▼
与现有记忆做向量相似度匹配
   │
   ├── 相似度 < 0.5 → CREATE（创建新记忆）
   │
   ├── 0.5 ≤ 相似度 < 0.8 → LLM 判断
   │      ├── 可以合并 → MERGE
   │      └── 补充细节 → UPDATE
   │
   └── 相似度 ≥ 0.8 → SKIP（已存在）
```

### 决策示例

| 新记忆 | 现有记忆 | 决策 | 原因 |
|--------|----------|------|------|
| "用户喜欢简洁回答" | "用户说不要太多废话" | MERGE | 高度相似，合并为一条 |
| "用户使用 VS Code" | 无 | CREATE | 全新信息 |
| "用户用 Python 3.11" | "用户用 Python" | UPDATE | 细节补充 |
| "用户叫张三" | "用户叫李四" | SKIP | 矛盾，但已有记录 |

## 💻 代码示例

### 自动记忆迭代

```python
client = ov.SyncOpenViking(path="./data")
client.initialize()

# 模拟多轮会话
scenarios = [
    ("user", "我叫张三，是后端工程师"),  # profile
    ("assistant", "好的，已记住"),
    ("user", "我写 Python 习惯用类型提示"),  # preference
    ("assistant", "了解，类型提示已记录"),
    ("user", "上次那个内存泄漏的 bug 怎么修的"),  # 检索案例
    ("assistant", "让我查一下..."),  # 使用了案例记忆
]

session = client.session(session_id="user_onboarding")

for role, text in scenarios:
    session.add_message(role, [{"type": "text", "text": text}])
    
    # 模拟记录上下文使用
    if role == "assistant":
        session.used(contexts=["viking://agent/memories/cases/memory-leak/"])

# 提交会话，触发记忆迭代
result = session.commit()
print(f"本次迭代:")
print(f"  - 提取记忆: {result['memories_extracted']}")
print(f"  - 更新计数: {result['active_count_updated']}")

# 下次交互时，Agent 已经"认识"用户了
client.close()
```
